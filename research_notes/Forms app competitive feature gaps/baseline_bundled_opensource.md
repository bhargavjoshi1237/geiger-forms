# Baseline Expectation Form Tools — Free/Bundled, Open-Source, and Forms Inside Work Tools (as of Oct 2026)

Scope: Google Forms, Microsoft Forms, Formbricks, OpnForm, HeyForm, Notion Forms, Airtable Forms/Interfaces, ClickUp Forms, monday WorkForms, HubSpot forms. Research conducted 2026-10-21. Dates are given wherever a source carries one; undated or pre-2025 material is flagged. Vendor comparison pages (Paperform, Jotform, Plumsail, AntForms, competitor "vs" pages) are treated as biased and marked as such.

## Google Forms and Microsoft Forms: current feature set, 2025–2026 AI features, and the limitations that push users to paid tools

### Takeaway
Both free tools now cover the core of forms (12-ish question types, section-based branching, quizzes with auto-grading, summary charts, a live link to Sheets/Excel, collaboration through Drive/M365), and both added generative AI in 2025–2026 (Gemini "Help me create", question suggestions, response summaries and theme percentages; Copilot drafting plus a new chat pane that edits, branches, sends invitations and analyses responses) — but the AI is gated to paid Workspace/Copilot licences. The limits that drive users to paid tools are consistent: no payments, file upload requires respondent sign-in (Google) or a work/school account (Microsoft, unverified), minimal design/branding and no custom domain, shallow logic (section jumps only, no calculations/piping), no creator-visible partial responses, and basic reporting.

### Cited Findings

**Google Forms — question types and structure**
- 12 question types: Short answer, Paragraph, Multiple choice, Checkboxes, Dropdown, File upload, Linear scale (0/1 to 2–10), Rating (stars/hearts/thumbs, 3–10), Multiple choice grid, Checkbox grid, Date, Time (time or duration) — [Google Docs Editors Help: question types](https://support.google.com/docs/answer/7322334?hl=en)
- Branching is section-based ("go to section based on answer"); the help page attaches section routing to Multiple choice and Dropdown (the fetched summary also attributes it to Checkboxes — Google historically restricts it to MC/Dropdown, so treat Checkboxes routing as unverified) — [Google Help: question types](https://support.google.com/docs/answer/7322334?hl=en)
- A 2026 review characterises "Go to section based on answer" as real branching that is "less sophisticated than dedicated tools but adequate for most screening and intake"; response validation constrains input — [Jet Admin review, 30 Sep 2026](https://www.jetadmin.io/blog/google-forms-review/)
- Rating question type added Oct 7, 2024, with averages/distributions in the Summary tab — [Google Workspace Updates (Forms label)](https://workspaceupdates.googleblog.com/search/label/Google%20Forms)

**Google Forms — quizzes & grading**

### Inferences
- The free tier has quietly absorbed "intake" basics (auto-close, response limits, granular respondent access, rating questions) only in 2024–2026, so the floor keeps rising; a new product must clear the 2026 floor, not the 2022 one.
- AI form drafting and AI response summarisation are now *expected* (both giants ship them) but sit behind paid licences in both — a bundled-AI story in Geiger Forms is a credible differentiator for suite users, not merely parity.
- The Sheets/Excel live link is the giants' real "integration": responses land in a grid where everything else happens. Geiger's equivalent is writing straight into Flow/Events/Campaign entities — a stronger version of the same habit.
- Recurring paid-tool triggers — payments, uploads from anonymous people, branding/custom domain, logic beyond section jumps (calculations, piping, hidden fields), partial-response capture, and post-submit workflows — are the clearest "clear-the-floor" targets.

### Gaps
- Could not render Microsoft's own Forms blog post or a current official Microsoft Forms feature list; question-type list and file-upload restrictions come from university help pages (undated) — verify whether Microsoft added new question types in 2025–2026.
- Whether Microsoft Forms supports native payments, partial responses, or custom branding beyond themes was not verified from a 2026 source.
- No official numeric file-size/storage limits for Google Forms uploads were found on the fetched help page.
- No source quantified *why* users switch (survey data); limitation lists come from reviewers and vendors with a stake.

## Open-source tools (Formbricks, OpnForm, HeyForm): self-hosting, in-app/website surveys, targeting, logic, integrations, licensing, positioning vs Typeform

### Takeaway
All three are AGPLv3 open-core: a fully functional free core you can self-host, with enterprise/paid features (branding removal, SSO, roles, advanced segments) unlocked by a licence key or cloud plan. They split by positioning: Formbricks is an "experience management" / "open-source Qualtrics alternative" with SDK-driven in-app and website surveys, triggers, targeting, cooldowns, contacts/segments and an AI feedback inbox; OpnForm is a Typeform/Google-Forms-style builder that wins on "unlimited forms and submissions free"; HeyForm is a conversational (one-question-at-a-time) Typeform-style builder with payments and drop-off analytics.

### Cited Findings

**Formbricks**
- Positions itself as an "Open Source Qualtrics Alternative"; survey types: in-app, website, link and email surveys; target user groups "without changing your application code"; integrations Slack, Notion, Zapier, n8n; TypeScript/Next.js stack; ~13.1k GitHub stars — [Formbricks GitHub README](https://github.com/formbricks/formbricks)
- Core AGPLv3 and fully functional; enterprise code in `apps/web/modules/ee` ships in the same Docker images but needs an Enterprise License Key; no white-label licences by default — [Formbricks GitHub](https://github.com/formbricks/formbricks); [Formbricks licence docs](https://formbricks.com/docs/self-hosting/advanced/license)
- Community Edition (free): unlimited surveys, responses and users; 1 workspace; all question types, advanced logic, custom styling, recall, hidden fields, partial responses, file upload, single-use links, PIN-protected surveys, full API, all SDKs, webhooks, email follow-ups, all integrations, multi-language surveys, Helm chart cluster hosting — [Formbricks licence docs](https://formbricks.com/docs/self-hosting/advanced/license)
- Enterprise-only: hide "Powered by Formbricks", whitelabel email, OIDC/SAML SSO, 2FA, teams & roles, contact management & segments, quota management, workflows, Unify Feedback Inbox, feedback datasets, insights dashboards, audit logs, reCAPTCHA spam protection; priced "pay per response / per workspace / per feature" (no public $) — [Formbricks licence docs](https://formbricks.com/docs/self-hosting/advanced/license)

### Inferences
- Open-source tools have pushed "unlimited forms and submissions for free" (OpnForm) and "partial responses, hidden fields, recall, multi-language free" (Formbricks CE) into the floor — features Google/Microsoft still lack — so the effective free floor is higher than the giants alone suggest.
- The consistent open-core gate is: branding removal, SSO, roles/teams, segments/contacts, audit logs, AI. That is the commercial line competitors draw; Geiger, already a suite with shared identity/roles, can include several of these at no marginal cost.
- Formbricks' in-product angle (SDK + triggers + attribute targeting + cooldown/recontact + "Unify" feedback inbox) is a distinct category (experience management) from form building; for Geiger it maps onto surveying users *inside* other suite apps (Flow, Events, Comms) and onto Campaign audiences rather than onto standalone link forms.
- OpnForm's MCP server and Formbricks' MCP-enabled API signal that agent-addressable forms (AI agents creating forms / reading submissions) are emerging as an open-source expectation in 2026.

### Gaps
- HeyForm's current free-tier limits were not visible on the pricing page (only a 7-day trial and "get started free"); whether a free cloud plan still exists is unconfirmed.
- Formbricks' conditional-logic depth (operators, variables, calculations) and question-type list were not fetched in detail.
- OpnForm's and HeyForm's logic capabilities (operators, branching vs show/hide) are only described at headline level in their READMEs.
- No independent (non-vendor) 2026 reviews of the three OSS tools were consulted; GitHub star counts are as displayed at fetch time.

## Forms inside work tools (Notion, Airtable, ClickUp, monday, HubSpot): how responses become rows/tasks/contacts, automations on submit, permissions, and gaps vs dedicated builders

### Takeaway
The suite-integrated pattern is consistent: a form is a *view onto a table*; each question maps 1:1 to a column/property; each submission creates exactly one native record (Notion page, Airtable record, ClickUp task, monday item, HubSpot contact); the record then flows into the tool's own automations, views and dashboards; and permissions are inherited from the workspace (internal-only vs public link vs anonymous). Their shared weaknesses vs dedicated builders are design/branding (paid-gated), shallow or plan-gated logic, little to no response analytics, and rigid record semantics (usually create-only, one record per submission, no multi-record/line-item creation).

### Cited Findings

**Notion Forms**
- Available on all plans; built on desktop/web only (not mobile); each question maps to a database property so question types match property types; each submission becomes a database page, landing in a "Responses" table view; forms built from scratch get an automatic "Respondent" property — [Notion Help: Forms](https://www.notion.com/help/forms)
- Sharing modes: "Anyone at {workspace} with link" (guests need DB access), "Anyone on the web with link" (responses automatically anonymous), "No access" (closed); for non-anonymous internal forms the creator sets respondent access to their own submission: No access / Can view / Can comment / Can edit / Full access — [Notion Help: Forms](https://www.notion.com/help/forms)
- Automations: triggers on new response or a specific answer; actions e.g. send status updates to respondents, Slack notifications; emailed copy of each submission; removing Notion branding on public forms needs a paid plan; Enterprise can block public forms workspace-wide — [Notion Help: Forms](https://www.notion.com/help/forms)
- Customisation is limited to title, description, icon, cover, submit button colour/text, confirmation title/body — [Notion Help: Forms](https://www.notion.com/help/forms)
- Conditional logic added late March 2025, Business plan and above only; conditions on Checkbox, Select, Multi-select; exact-match only, no AND/OR, each condition tied to a single input, no text "contains", nesting only two levels deep — [Notion Mastery, 26 Mar 2025](https://notionmastery.com/notion-added-conditional-logic-to-forms/); help centre confirms Business/Enterprise and multiple-choice basis — [Notion Help](https://www.notion.com/help/forms)
- Limits: high-volume forms load slowly (Notion suggests a second form or deleting old responses); form views can't be exported — [Notion Help: Forms](https://www.notion.com/help/forms)
- Third-party guides report submissions can only create new pages, not update existing ones; relation-picker options can't be filtered; confirmation page options are limited — [Notioneers guide](https://notioneers.eu/en/insights/notion-forms-guide) / [WorkManagementHub 2026 guide](https://workmanagementhub.com/notion-forms-setup-guide-2026/) (surfaced via search summary; not verified on Notion's help page)

**Airtable (form builder, legacy form view, interface forms)**
- Form builder is on all plans; anyone with a share link can submit without an Airtable account; it is the recommended successor to the legacy form view, which "won't receive the newest features" — [Airtable Support: building and sharing forms](https://support.airtable.com/articles/9431794285-building-and-sharing-forms-in-airtable); [Airtable Support: interface form layout](https://support.airtable.com/docs/airtable-interface-layout-form)
- Field types incl. select, linked record, user, attachment, number, currency, percent, duration, URL, email, text; computed fields not supported; up to four fields side by side, grouped sections; default values (editable or locked); URL prefill — [Airtable Support](https://support.airtable.com/articles/9431794285-building-and-sharing-forms-in-airtable)
- Conditional field visibility on all plans; conditional *groups* need Business/Enterprise Scale; logic not supported in iOS/Android interface experiences; hidden fields "aren't secure" — [Airtable Support](https://support.airtable.com/articles/9431794285-building-and-sharing-forms-in-airtable); [Airtable form permissions](https://support.airtable.com/articles/4485740655-airtable-form-permissions)
- Paid-only: cover image, logo, hiding Airtable branding, data validation (email format, char limits, numeric ranges, attachment MIME types, URL), domain restriction; Business+: org-wide sharing; public forms can be password-protected; embeds; static redirects (not in embeds) — [Airtable Support](https://support.airtable.com/articles/9431794285-building-and-sharing-forms-in-airtable)
- Each submission creates exactly one record in the fixed source table; cannot create multiple linked line-item records (needs an automation); "When a form is submitted" automation trigger; native "Send an email" for confirmations; collaborators added to user fields aren't auto-notified — [Airtable Support](https://support.airtable.com/articles/9431794285-building-and-sharing-forms-in-airtable)
- Limits: 50 forms per base; source table can't be changed; attachments over the per-file limit (documented 5 MB) can fail silently; heavy linked-record forms slow under traffic; deleted fields block submissions — [Airtable Support](https://support.airtable.com/articles/9431794285-building-and-sharing-forms-in-airtable)
- Interface forms are visible only to logged-in users with edit access to that interface (not public); read-only/commenter collaborators can't submit; linked records can be selected but not created; linked fields can't be prefilled from the opening record ("known limitation") — [Airtable Support: interface form layout](https://support.airtable.com/docs/airtable-interface-layout-form)
- Vendor claim: Airtable forms can't be split into sections, logic is restricted, branding not supported — [Plumsail (vendor)](https://plumsail.com/blog/forms-airtable-record/) (partly contradicted by Airtable's own docs, which now support grouped sections)

**ClickUp Forms**
- Each submission becomes a task in a chosen List, with assignee, priority and Custom Fields filled from the form; routing to the right List/owner; share by link, embed, or restrict to Workspace members; guests submit without a ClickUp account; Submission Table view filters by status/date/submitter; "Free forever" — [ClickUp Forms feature page](https://clickup.com/features/forms?lang=en)
- AI: ClickUp Brain reviews submissions for missing info/vague descriptions/blank required fields and prompts the submitter to fix them before the task is created; catches duplicates; "Super Agents" assign priority and route to reviewers — [ClickUp Forms feature page](https://clickup.com/features/forms?lang=en)
- Conditional logic: up to 25 rules per field, multiple conditions per rule; action "Add field" inserts a field into the submission task (e.g., Urgent priority → Due Date field appears) — [ClickUp Help: conditional logic in Forms](https://help.clickup.com/hc/en-us/articles/30720189184791-Use-conditional-logic-in-Forms) (via search summary; direct fetch returned 403)
- Gap: applying a different task template based on an answer (e.g., Bug vs Question) is a feature request marked "not on the roadmap" — [ClickUp Feedback](https://feedback.clickup.com/feature-requests/p/apply-task-template-based-on-selected-option-in-conditional-logic-form)

**monday WorkForms**
- Submissions "create or update items on new or existing monday.com boards", then trigger automations/integrations and feed dashboards; conditional logic incl. subitem questions and editable responses; brand colours, fonts, layouts, custom welcome/thank-you pages with logo; AI Form Builder from prompts, AI Translations (Enterprise), AI Insights summarising long-text responses into categories/trends — [monday WorkForms product page](https://monday.com/w/workforms)
- Conditional questions display only when a previous answer meets a condition — [monday Support: conditional logic in WorkForms](https://support.monday.com/hc/en-us/articles/27989721912722-Using-conditional-logic-in-WorkForms); nested conditions supported for single select, multi-select, yes/no (monday blog, via search summary)
- Questions map to columns (e.g., Upload file → Files column) — [monday Support: question types](https://support.monday.com/hc/en-us/articles/22630036771986-WorkForms-question-types) (via search summary; direct fetch 403)
- WorkForms included in monday plans but "certain WorkForms features may require payment in the future" — [monday Support: Get started](https://support.monday.com/hc/en-us/articles/360000358700-Get-started-with-WorkForms)
- Conflict: product page says submissions can *update* existing items; third-party sources say WorkForms can only create new items (an existing item can only be linked via a connected-boards question) — [TaskRhino limitations](https://www.taskrhino.ca/blog/monday-com-workforms-limitations-and-workarounds/); [monday forms-builder skill doc](https://www.skills.sh/mondaycom/skills/forms-builder) vs [monday product page](https://monday.com/w/workforms)
- Community-reported limits: can't map answers from different (conditional) questions into the same column — [monday Community](https://community.monday.com/t/create-multiple-conditional-questions-on-your-form-that-report-to-the-same-column/36918); third-party claims of branding removal only on Pro/Enterprise and conditional logic Enterprise-only (unverified, competitor sources) — [Jotform: WorkForms pricing](https://jotform.com/blog/workforms-pricing); [Till Freitag](https://till-freitag.com/en/blog/monday-workforms-alternatives)

**HubSpot forms**
- Fields store data in CRM properties; submissions create a new contact for unknown emails or update existing contacts; set lifecycle stage on submit; data-enrichment form shortening; campaign association (Marketing Pro+); notify contact owner/users/teams; block domains/free email providers; connect to help desk to create tickets (Service Hub Pro+) — [HubSpot KB: create and edit forms, updated Oct 9, 2026](https://knowledge.hubspot.com/forms/create-and-edit-forms)
- Field types: single/multi-line text, phone, single/multiple checkboxes, dropdown, radio, date picker, number, file, email (calculation, rollup, rich text, URL properties not supported) — [HubSpot KB](https://knowledge.hubspot.com/forms/create-and-edit-forms)
- Multi-step forms up to 20 steps on Starter/Pro/Enterprise; progress bar needs Marketing Starter+; conditional logic requires Marketing/Content Hub Professional or Enterprise (show/hide fields, text, images, steps; redirect after submit); "Skip to step" being deprecated — [HubSpot KB](https://knowledge.hubspot.com/forms/create-and-edit-forms)
- Rule limits conflict: 200 rules × 10 conditions per form in the Oct 2026 KB vs 100 rules × 10 conditions in the May 28, 2026 new-editor page — [HubSpot KB (Oct 2026)](https://knowledge.hubspot.com/forms/create-and-edit-forms) vs [HubSpot KB: new form editor](https://knowledge.hubspot.com/forms/create-and-edit-forms-using-the-new-form-editor)
- Post-submit: simple follow-up emails, or custom workflows triggered on form submission; cookie-based prefill of known values for returning visitors; Breeze AI generates images/content and translates forms (Pro+); raw HTML only in legacy editor — [HubSpot KB](https://knowledge.hubspot.com/forms/create-and-edit-forms)
- Free-tier forms carry HubSpot branding that can't be removed without upgrading (community answer, not official policy) — [HubSpot Community](https://community.hubspot.com/t5/Lead-Capture-Tools/How-to-remove-quot-free-form-with-hubspot-quot/td-p/823020)
- "Non-HubSpot forms" (collected forms) capture submissions from external HTML forms via the tracking code; up to 10,000 forms per account (KB updated Jan 10, 2026) — [HubSpot KB: non-HubSpot forms](https://knowledge.hubspot.com/forms/use-non-hubspot-forms)

### Inferences
- The integration contract that users now expect from a suite form: (1) question ⇄ field mapping that edits the underlying schema (Airtable even changes the source field type from the form), (2) one submission → one native record, (3) automation trigger "on form submitted" plus "on specific answer", (4) inherited workspace permissions with internal / public / anonymous modes, (5) respondent access to their own submission (Notion's view/comment/edit levels), (6) notifications to owners. Geiger Forms writing into Flow tasks, Events registrations, Campaign contacts and Dashboards is exactly this pattern — and is table stakes for a suite, not a differentiator by itself.
- Where the work-tool forms are weakest — and where Geiger could differentiate — is record semantics: updating an existing record (Notion/monday-create-only per third parties), creating multiple linked records from one submission (Airtable can't), choosing a template/type by answer (ClickUp "not on roadmap"), and writing across *multiple* apps from one form (e.g., an event registration that creates an Events attendee, a Campaign contact and a Flow follow-up task). No work tool found does cross-app fan-out natively.
- The second weakness is dedicated-builder depth: logic is plan-gated (Notion Business+, HubSpot Pro+, Airtable groups Business+) and shallow (Notion exact-match, 2 levels); design/branding is paid-gated (Notion, Airtable, HubSpot); analytics are essentially absent (responses are rows; charts come from the tool's dashboards). A suite form that ships Typeform-grade logic and design *plus* native write-through would beat both camps.
- AI in work-tool forms has shifted from "generate a form" to "improve the submission": ClickUp Brain validating submissions before the task is created and monday AI Insights summarising long text are signals that AI triage/enrichment at submit time is the 2026 frontier for intake forms.

### Gaps
- ClickUp help and monday support pages returned 403 to direct fetch; their details come from search-result summaries of those official pages.
- ClickUp and monday free-plan limits (number of forms/submissions, branding removal, logic tier) were not confirmed from official pricing pages.
- Notion's file-upload question support (Files & media property) and whether Notion forms can update existing pages were not confirmed on Notion's own help page.
- HubSpot free-tier forms limits (number of forms, branding) not confirmed from an official HubSpot page; whether HubSpot offers AI *form generation* (vs content/images) not confirmed.
- No usage data found on how many teams use built-in work-tool forms vs dedicated builders.

## Table stakes vs features missing even from the big free tools

### Takeaway
True table stakes across every tool researched: core field types (text, choice, date, file upload — with caveats), some show/hide or branching logic (though gated in several work tools), shareable link + embed, responses stored as rows in a grid/database, email notifications, and basic response export. Increasingly expected but paid-gated: AI drafting and AI response summaries, branding removal. Missing even from Google/Microsoft Forms (and usually the work tools): payments, anonymous file upload, custom domain/full branding, calculations/answer piping/hidden fields, creator-visible partial responses, in-app/targeted surveys, and multi-record/cross-app write-through.

- **True table stakes** (Geiger Forms must have on day one, free): the 12-ish standard field types incl. file upload that works for anonymous respondents, section/page structure, show/hide logic, required/validation, share link + embed + internal-only mode, response table with export, owner notifications, summary charts, quiz/scoring mode, auto-close by date/response cap, and an "on submit" automation hook into the suite.
